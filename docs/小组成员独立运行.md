# 从仓库下载后运行

1. 在仓库首页选择 Code → Download ZIP 并解压，或用 Git 克隆仓库。
2. 在同一仓库的 Releases 下载本次 wildlife8-data-models.zip，放在解压后项目根目录的上一级。
3. 按 [README](../README.md)创建Python 3.12环境、安装依赖并导入附件。
4. 执行数据检查和Demo；想重新训练时按 [实验设计](EXPERIMENTS.md)每次执行一项。
5. 新运行写入独立时间戳目录，不覆盖已交付成绩。不要把虚拟环境、原图、权重或新实验批量提交到Git历史。

配置说明见 [统一配置与运行](统一配置与运行.md)。无NVIDIA GPU的电脑可直接阅读报告、PPT及保存的预测图；现有训练和Demo命令按GPU环境提供。
