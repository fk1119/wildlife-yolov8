# 小组成员独立运行

1. 每人使用独立项目副本，按[安装与复现](REPRODUCE.md)建立自己的Python 3.12环境。
2. 仅做图片演示时使用已有权重；重新训练时取得完整数据，按[附件说明](../DATA_ASSET.md)导入。
3. 先执行对应实验的 `--check-only`，通过后再训练；完整命令见[实验入口](EXPERIMENT_NAMES.md)。
4. 保留自己新运行目录中的配置、日志、训练CSV、指标和权重。已有正式结果不等于本人重新训练的结果。

当前训练和Demo需要NVIDIA GPU；无GPU时可阅读报告和保存的预测图。上传时保留指定正式模型与证据，避免把整个虚拟环境、缓存、原始数据和新运行目录批量加入Git。
