# 统一配置与运行

配置位于根目录的 `config.json`。所有五项实验和报告共用 `scripts/project_config.py` 读取配置；`run.py` 只负责选择实验并调度。当前脚本名见[五项实验入口](EXPERIMENT_NAMES.md)，旧脚本文件名不再使用；run.py保留旧短命令别名。run.py只接受实验名、--config、--check-only及实验三的--resume-run，不接受--epochs等训练参数；统一入口调参请修改config.json。直接调用支持这些参数的实验脚本时，显式参数覆盖配置。Demo和部分历史工具不读取统一配置。

## 配置字段

| 字段 | 含义 |
|---|---|
| paths.data | 数据根目录，含images和labels |
| paths.initial_weights | 初始预训练权重文件 |
| paths.output | 新实验输出根目录 |
| paths.baseline_run | 鲁棒性实验使用的参考训练目录，含args.yaml和weights/best.pt |
| runtime.device | NVIDIA显卡编号，默认0；当前不支持CPU训练 |
| runtime.workers | 数据加载进程数，Windows默认0 |
| training.epochs / batch / seed | 尺寸、Mosaic实验的训练轮数、批大小、种子；模糊比例使用epochs和batch |
| experiments.inference_sizes.sizes | 同一模型的两个推理尺寸，第一个尺寸用于训练 |
| experiments.training_sizes.sizes | 两套匹配的训练/测试尺寸 |
| experiments.mosaic.imgsz | Mosaic对照的训练/测试尺寸 |
| experiments.blur_ratios.imgsz / seeds | 模糊比例实验的尺寸和种子列表 |
| experiments.robustness | 参考基线配对协议，固定30轮、batch8、416、种子42/43；改动会报错，用于保持基线配对条件一致 |

相对路径以config.json所在目录为基准，与终端当前目录无关；默认配置随项目移动，无需改D盘路径。可填自己的绝对路径指向外置数据盘。框架使用的dataset.yaml由入口根据配置自动生成，不需要手工再维护第二份配置。保留原八类数据和初始权重哈希约束，换数据集或模型属于另一个实验设计，需另行调整数据和模型校验方案。

## 安装与资源（每台电脑只做一次）

以下仅适用于新环境。当前电脑已有环境的设置见[复现步骤](REPRODUCE.md)。数据包应先实际取得，路径以[附件说明](../DATA_ASSET.md)为准；本机数据已齐时无需导入。

```powershell
py -3.12 -m venv .venv
$py = '.\.venv\Scripts\python.exe'
& $py -m pip install -r requirements-course.txt
& $py -X utf8 scripts/import_resources.py --archive '实际资源包ZIP路径'
```

导入器按标准相对目录恢复附件。若已有外置数据/模型，直接在config.json中指定位置即可。解释器路径按安装位置设置。

## 每次运行

```powershell
# 在同一窗口定义一次；现有环境用户可继续使用自己的$py
$py = '.\.venv\Scripts\python.exe'

# 预检：只检查，不训练
& $py -X utf8 run.py experiment3_mosaic --check-only

# 每次只执行下面一项，完成后再执行下一项
& $py -X utf8 run.py experiment1_inference_sizes
& $py -X utf8 run.py experiment2_training_sizes
& $py -X utf8 run.py experiment3_mosaic
& $py -X utf8 run.py experiment4_robustness
& $py -X utf8 run.py experiment5_blur_ratios
```

每项均自动新建时间戳目录；鲁棒性结束后自动汇总报告。鲁棒性复用配置指定的seed42参考模型，其余三个模型从COCO权重重新微调；不是四个模型全部重新训练，也不是随机初始化训练。新实验目录保存effective_config.json及原有protocol.json，后者记录实际训练参数。旧实验不会因修改配置而自动重写。

自定义配置文件也可使用 `--config '自己的配置文件.json'`。显式指定配置文件时，资源相对路径以该文件所在目录为基准。不同配置在独立项目副本中运行。

Mosaic同机恢复：`& $py -X utf8 run.py experiment3_mosaic --resume-run '实际中断目录'`。恢复只复用完整训练结果并补齐缺失组或评估；发现不完整训练会拒绝，不是任意epoch断点续训。恢复使用原protocol.json的轮数、尺寸、batch和种子，不用新配置改变已开始的对照；请保持数据和模型位置不变。跨机器移动后建议新建实验。

检查范围和日期见[当前检查记录](VALIDATION_CURRENT.md)。
