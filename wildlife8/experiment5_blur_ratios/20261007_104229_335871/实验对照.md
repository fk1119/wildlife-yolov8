# 模糊增强比例对照

验证集按预设清晰/模糊等权规则选择：50%。测试结果仅用于报告，不重新选择比例。

| 模糊比例 | 测试条件 | 平均mAP50–95 | 相对0%变化/百分点 |
|---|---|---|---|
| 0% | clean | 75.11% | +0.00 |
| 0% | blur | 64.80% | +0.00 |
| 0% | dark | 69.71% | +0.00 |
| 0% | jpeg | 68.48% | +0.00 |
| 25% | clean | 75.22% | +0.11 |
| 25% | blur | 71.49% | +6.69 |
| 25% | dark | 70.60% | +0.89 |
| 25% | jpeg | 68.75% | +0.28 |
| 50% | clean | 73.55% | -1.55 |
| 50% | blur | 71.62% | +6.82 |
| 50% | dark | 69.78% | +0.07 |
| 50% | jpeg | 67.12% | -1.35 |

blur/dark/jpeg分别先对三个强度平均，再对种子平均；clean只对种子平均。各个种子的结果见comparison.csv。

所有模型从同一预训练权重开始。25%模糊样本包含在50%组内，重合样本的模糊强度相同；原数据不修改。

这是人工退化和有限随机种子的结果，不能证明真实环境下普遍有效或统计显著。测试集此前已被查看，本实验不是新的盲测。
